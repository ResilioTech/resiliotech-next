Your AWS bill just hit $8,000. Last month it was $1,200. What happened?

Someone left a NAT Gateway running in `us-east-2`. Another person launched a `p3.16xlarge` instance for testing and forgot to turn it off. Your RDS instance grew to 500GB without anyone noticing.

This is preventable. Here's how we set up cost guardrails for every [Founding Pilot client](/founding-pilot) to catch expensive mistakes *before* they hit your credit card.

## The Cost Control Stack

We implement four layers of defense:

1. **Budgets:** Alert when spend exceeds thresholds
2. **Policies:** Block expensive resource types
3. **Anomaly Detection:** Catch unexpected spikes
4. **Showback:** Per-team/per-service cost visibility

Let's build each one in Terraform.

## Layer 1: AWS Budgets

### Monthly Budget with Email Alerts

```hcl
# terraform/budgets.tf

resource "aws_budgets_budget" "monthly" {
  name              = "monthly-budget"
  budget_type       = "COST"
  limit_amount      = "1000"
  limit_unit        = "USD"
  time_period_start = "2025-01-01_00:00"
  time_unit         = "MONTHLY"

  # Alert at 50%, 80%, 100%, and 120% of budget
  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 50
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["founders@yourstart.com"]
  }

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 80
    threshold_type             = "PERCENTAGE"
    notification_type          = "FORECASTED"  # Alert before hitting limit
    subscriber_email_addresses = ["founders@yourstart.com", "devops@yourstart.com"]
  }

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 100
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["founders@yourstart.com"]
    subscriber_sns_topic_arns  = [aws_sns_topic.cost_alerts.arn]
  }

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 120
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["founders@yourstart.com"]
    subscriber_sns_topic_arns  = [aws_sns_topic.cost_alerts_critical.arn]
  }

  cost_filters = {
    TagKeyValue = ["user:Environment$production"]  # Only track prod costs
  }
}
```

### Per-Service Budgets

```hcl
locals {
  service_budgets = {
    "api"       = 300
    "frontend"  = 100
    "database"  = 200
    "analytics" = 150
  }
}

resource "aws_budgets_budget" "service" {
  for_each = local.service_budgets

  name              = "${each.key}-monthly-budget"
  budget_type       = "COST"
  limit_amount      = each.value
  limit_unit        = "USD"
  time_period_start = "2025-01-01_00:00"
  time_unit         = "MONTHLY"

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 90
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["team-${each.key}@yourstart.com"]
  }

  cost_filters = {
    TagKeyValue = ["user:Service$${each.key}"]
  }
}
```

### SNS Topic for Critical Alerts (e.g., Slack/PagerDuty)

```hcl
resource "aws_sns_topic" "cost_alerts_critical" {

resource "aws_sns_topic_subscription" "slack" {
```

## Layer 2: Service Control Policies (SCPs)

Block expensive instance types and regions:

```hcl
# terraform/scp.tf

data "aws_iam_policy_document" "deny_expensive_instances" {
  statement {
    sid    = "DenyExpensiveEC2"
    effect = "Deny"

    actions = [
      "ec2:RunInstances",
    ]

    resources = [
      "arn:aws:ec2:*:*:instance/*",
    ]

    condition {
      test     = "StringEquals"
      variable = "ec2:InstanceType"

      # Block GPU and high-memory instances in non-prod
      values = [
        "p3.*",
        "p4.*",
        "g4dn.*",
        "r5.*xlarge",
        "r6.*xlarge",
      ]
    }

    condition {
      test     = "StringNotEquals"
      variable = "aws:RequestedRegion"
      values   = ["us-east-1"]  # Only allow primary region
    }
  }

  statement {
    sid    = "DenyNonPrimaryRegions"
    effect = "Deny"

    actions = [
      "ec2:*",
      "rds:*",
      "elasticloadbalancing:*",
    ]

    resources = ["*"]

    condition {
      test     = "StringNotEquals"
      variable = "aws:RequestedRegion"
      values   = ["us-east-1", "us-west-2"]  # Primary + DR region only
    }
  }
}

resource "aws_organizations_policy" "cost_control" {
  name        = "cost-control-policy"
  description = "Prevent expensive resource creation"
  content     = data.aws_iam_policy_document.deny_expensive_instances.json
}

resource "aws_organizations_policy_attachment" "dev_account" {
  policy_id = aws_organizations_policy.cost_control.id
  target_id = "ou-xxxx-xxxxxxxx"  # Your development OU
}
```

## Layer 3: Cost Anomaly Detection

AWS Cost Anomaly Detection uses ML to find unusual spend:

```hcl
resource "aws_ce_anomaly_monitor" "service_monitor" {
  name              = "ServiceCostMonitor"
  monitor_type      = "DIMENSIONAL"
  monitor_dimension = "SERVICE"
}

resource "aws_ce_anomaly_subscription" "alerts" {
  name      = "cost-anomaly-alerts"
  frequency = "DAILY"

  monitor_arn_list = [
    aws_ce_anomaly_monitor.service_monitor.arn,
  ]

  subscriber {
    type    = "EMAIL"
    address = "founders@yourstart.com"
  }

  subscriber {
    type    = "SNS"
    address = aws_sns_topic.cost_alerts.arn
  }

  threshold_expression {
    dimension {
      key           = "ANOMALY_TOTAL_IMPACT_ABSOLUTE"
      values        = ["100"]  # Alert if anomaly > $100
      match_options = ["GREATER_THAN_OR_EQUAL"]
    }
  }
}
```

## Layer 4: Cost Showback with Tags

Tag every resource with service/team/environment:

```hcl
# terraform/tagging.tf

locals {
  common_tags = {
    ManagedBy   = "terraform"
    Environment = var.environment
    Service     = var.service_name
    Team        = var.team_name
    CostCenter  = var.cost_center
  }
}

resource "aws_instance" "app" {
  # ... other config ...

  tags = merge(
    local.common_tags,
    {
      Name = "${var.service_name}-${var.environment}"
    }
  )
}
```

### Enforce Tagging with AWS Config

```hcl
resource "aws_config_config_rule" "required_tags" {
  name = "required-tags"

  source {
    owner             = "AWS"
    source_identifier = "REQUIRED_TAGS"
  }

  input_parameters = jsonencode({
    tag1Key = "Environment"
    tag2Key = "Service"
    tag3Key = "Team"
  })

  scope {
    compliance_resource_types = [
      "AWS::EC2::Instance",
      "AWS::RDS::DBInstance",
      "AWS::ElasticLoadBalancingV2::LoadBalancer",
    ]
  }
}

resource "aws_config_remediation_configuration" "tag_remediation" {
  config_rule_name = aws_config_config_rule.required_tags.name

  target_type      = "SSM_DOCUMENT"
  target_identifier = "AWS-PublishSNSNotification"

  parameter {
    name         = "AutomationAssumeRole"
    static_value = aws_iam_role.config_remediation.arn
  }

  parameter {
    name         = "TopicArn"
    static_value = aws_sns_topic.cost_alerts.arn
  }

  parameter {
    name         = "Message"
    static_value = "Resource is missing required cost allocation tags!"
  }

  automatic                  = false
  maximum_automatic_attempts = 3
  retry_attempt_seconds      = 60
}
```

## Cost Optimization Rules (Bonus)

### Auto-Stop Non-Prod Instances at Night

```hcl
resource "aws_lambda_function" "stop_instances" {
  filename      = "stop_instances.zip"
  function_name = "stop-dev-instances"
  role          = aws_iam_role.lambda_exec.arn
  handler       = "index.handler"
  runtime       = "python3.11"

  environment {
    variables = {
      TAG_KEY   = "Environment"
      TAG_VALUE = "development"
    }
  }
}

resource "aws_cloudwatch_event_rule" "stop_schedule" {
  name                = "stop-dev-instances-nightly"
  description         = "Stop development instances at 7 PM"
  schedule_expression = "cron(0 19 * * ? *)"  # 7 PM UTC
}

resource "aws_cloudwatch_event_target" "lambda" {
  rule      = aws_cloudwatch_event_rule.stop_schedule.name
  target_id = "StopInstancesLambda"
  arn       = aws_lambda_function.stop_instances.arn
}

resource "aws_lambda_permission" "allow_cloudwatch" {
  statement_id  = "AllowExecutionFromCloudWatch"
  action        = "lambda:InvokeFunction"
  function_name = aws_lambda_function.stop_instances.function_name
  principal     = "events.amazonaws.com"
  source_arn    = aws_cloudwatch_event_rule.stop_schedule.arn
}
```

**Lambda function (`stop_instances.py`):**
```python
import boto3
import os

ec2 = boto3.client('ec2')

def handler(event, context):
    tag_key = os.environ['TAG_KEY']
    tag_value = os.environ['TAG_VALUE']

    instances = ec2.describe_instances(
        Filters=[
            {'Name': f'tag:{tag_key}', 'Values': [tag_value]},
            {'Name': 'instance-state-name', 'Values': ['running']}
        ]
    )

    instance_ids = []
    for reservation in instances['Reservations']:
        for instance in reservation['Instances']:
            instance_ids.append(instance['InstanceId'])

    if instance_ids:
        ec2.stop_instances(InstanceIds=instance_ids)
        print(f"Stopped {len(instance_ids)} instances: {instance_ids}")

    return {
        'statusCode': 200,
        'body': f'Stopped {len(instance_ids)} instances'
    }
```

## Cost Dashboard (CloudWatch)

Visualize costs in a CloudWatch dashboard:

```hcl
resource "aws_cloudwatch_dashboard" "costs" {
  dashboard_name = "cost-monitoring"

  dashboard_body = jsonencode({
    widgets = [
      {
        type = "metric"
        properties = {
          metrics = [
            ["AWS/Billing", "EstimatedCharges", { stat = "Maximum", label = "Total Cost" }]
          ]
          period = 86400
          stat   = "Maximum"
          region = "us-east-1"
          title  = "Monthly Estimated Charges"
        }
      },
      {
        type = "metric"
        properties = {
          metrics = [
            ["AWS/EC2", "EstimatedCharges", { stat = "Maximum" }],
            ["AWS/RDS", "EstimatedCharges", { stat = "Maximum" }],
            ["AWS/S3", "EstimatedCharges", { stat = "Maximum" }]
          ]
          period = 86400
          stat   = "Maximum"
          region = "us-east-1"
          title  = "Cost by Service"
        }
      }
    ]
  })
}
```

```hcl
resource "aws_spot_instance_request" "dev" {
  ami           = "ami-xxxxxxxx"
  instance_type = "t3.medium"
  spot_price    = "0.05"  # 70% cheaper than on-demand

  tags = merge(local.common_tags, {
    Name = "dev-spot-instance"
  })

```

### 3. S3 Lifecycle Policies
```hcl
resource "aws_s3_bucket_lifecycle_configuration" "logs" {
  bucket = aws_s3_bucket.logs.id

  rule {
    id     = "transition-old-logs"
    status = "Enabled"

    transition {
      days          = 30
      storage_class = "STANDARD_IA"  # Cheaper storage
    }

    transition {
      days          = 90
      storage_class = "GLACIER"  # Even cheaper
    }

    expiration {
      days = 365  # Delete after 1 year
    }
  }
}
```
